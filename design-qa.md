# Проверка заготовки панели хостинга

Источник — панель Timeweb Hosting в авторизованной вкладке Chrome. Сравнение выполнено по снимку страницы аккаунта и по снимку локальной сборки. Логотип и иконки сверены с компонентами Main Header и Sidebar Menu в библиотеке VH Design System.

## Широкий экран

- Исходный снимок сделан при масштабе 2×. Сравнение выполнено в CSS-пикселях с локальной областью 1728 × 866.
- Шапка высотой 76 px. Сайдбар шириной 256 px начинается на 32 px ниже шапки. Промежуток до основной области — 40 px.
- Порядок и группировка пунктов меню совпадают с библиотекой. Иконки и логотип отрисовываются из SVG. Цвета и параметры текста читаются из выгрузки VH.
- Основная область пуста. Выбор раздела подсвечивает соответствующий пункт. Проверены открытие меню поддержки, закрытие при выборе пункта и доступ к каталогу по `/?catalog`.

## Узкий экран

- Локальная проверка при 390 × 844. Кнопка меню открывает сайдбар, выбор раздела сворачивает его. Пустой лист остаётся доступен.
- Адаптивное поведение разработано для заготовки. Мобильный вариант исходной панели отдельно не сравнивался.

Данные в шапке демонстрационные. Ошибок JavaScript при проверке локальной сборки не обнаружено.

Повторная сверка с продакшеном охватила открытые меню поддержки и аккаунта, стрелки и активный пункт сайдбара. Проверены белая стрелка вверх при раскрытии, ширина выпадающего меню 252 px, тёмный текст и синяя иконка активного пункта, переключение темы и закрытие меню по Escape.
