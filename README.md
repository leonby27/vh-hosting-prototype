# VH Design System

Локальный проект для работы с дизайн-системой VH и подготовки макетов на её основе. Источник данных — [библиотека VH в Figma](https://www.figma.com/design/3u9Sq9ppjXUlB4PwzkDV9R/VH---Design-System).

Данные выгружены через Figma MCP 12 ноября 2026 года.

## Запуск и сборка

Проект использует React и Vite. Требуется Node.js 20.19+ или 22.12+ из поддерживаемой ветки Node.js.

```sh
npm ci
npm run dev
```

Чтобы собрать статический сайт, выполните `npm run build`. Готовые файлы появятся в папке `dist`. Для локальной проверки сборки выполните `npm run preview`. При обновлении выгрузок повторите сборку.

На главной открывается дашборд панели Timeweb Hosting. `src/HostingShell.jsx` содержит шапку и боковую навигацию. `src/Dashboard.jsx` реализует карточки баланса, тарифа и сервисов, график нагрузки и блок FTP. [Макет дашборда в Figma](https://www.figma.com/design/PiKbmjMN3EljWSe3RRsNjt/VH---Layouts?node-id=70624-114261).

Данные аккаунта, FTP и действия в навигации демонстрационные. Каталог дизайн-системы доступен по адресу `/?catalog`. Шрифт Stem используется при наличии на устройстве.

В служебном меню есть блок «Что изменится» (`/?changes`). `PlanChanges` принимает строки изменений, уведомления, итоговые суммы, способы оплаты и действия как свойства. Изменения элементов передаются через `onChange`, действия — через `onAction`. В `PlanChangesPreview` вкладка «Динамический» показывает интерактивный сценарий оплаты, а «Полный» — все образцы из адаптивных фреймов Figma. Сценарий с сохранённой картой можно открыть через «Состояния страницы» или пройти демо-оплату картой с включённым флажком «Сохранить».

Под динамическим примером находится галерея `PlanChangesScenarios`. Каждый пример передаёт в `PlanChanges` данные одного сценария: состав услуг, итог, уведомления и подходящее действие.

В разделе «Сайты» по умолчанию открывается «Мои сайты». Вкладка «Сетевая защита» (`/?sites=network-protection`) повторно использует `PlanChanges` для выбранных доменов. Защита стоит 300 ₽ в месяц за аккаунт. После подключения услуги список доменов можно менять без доплаты.

Правое меню в шапке открывает панель состояний. На вкладке «Сетевая защита» можно сразу открыть выбор доменов, подключённую защиту с автопродлением или без него, все статусы доменов, список из 50 доменов и оплату без сохранённой карты. «Исходное состояние» сбрасывает данные прототипа. Демо-оплата запускает подключение, а в строках «Ждём DNS» и «Требуется действие» можно имитировать проверку записи через «Инструкцию». «Получить счёт» открывает блок ожидания оплаты с демо-счётом для скачивания. Квитанция добавляет отдельный шаг имитации оплаты.

## Цвета

[colors.json](colors.json) содержит 190 цветовых переменных коллекции `Theme VH` и 117 стилей заливки. У каждой переменной есть значения для `Light` и `Dark`. В JSON сохранены точные значения каналов из Figma и округлённое представление HEX с альфа-каналом для полупрозрачных цветов.

| Переменная | Light | Dark |
| --- | --- | --- |
| `Base/Background` | `#F5F6F8` | `#14161B` |
| `Base/On Background` | `#FFFFFF` | `#21262D` |
| `Base/Surface` | `#F5F6F8` | `#2B3039` |
| `Base/Line/Default Line` | `#E8EBEF` | `#31394A` |

Для нового макета найдите нужную переменную по имени и возьмите значение из `valuesByMode`. Имена и идентификаторы режимов хранятся в `collection.modes`. Отдельный раздел `paintStyles` содержит именованные стили заливки из Figma.

## Типографика

[typography.json](typography.json) содержит 42 текстовых стиля семейства **Stem** в начертаниях Regular, Medium и Bold. Для каждого стиля сохранены имя, семейство, начертание, размер, высота строки, межбуквенный интервал и параметры абзаца.

| Стиль | Начертание | Размер | Высота строки |
| --- | --- | --- | --- |
| `Display Large 40px/Bold` | Bold | 40 px | 56 px |
| `Text Large 16px/Regular` | Regular | 16 px | 20 px |
| `Text Small 14px/Regular` | Regular | 14 px | 16 px |

Для отображения шрифта в макете нужен доступ к Stem в используемом редакторе или приложении. Экспорт содержит параметры стилей.

## Обновление

После изменений в Figma повторно выгрузите переменные, стили заливки и текстовые стили из исходного файла. Сверяйте изменения по идентификаторам Figma, чтобы отличить переименование от удаления и добавления. Обновите дату выгрузки в обоих JSON-файлах и здесь.
