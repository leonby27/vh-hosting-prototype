# Выпадающие меню

Для всех выпадающих меню и панелей выбора поверх страницы используйте `DropdownPanel` из `src/hosting-motion.jsx`. Передавайте в него `open` и связывайте кнопку с панелью через `aria-expanded` и `aria-controls`. Оставляйте панель в DOM при закрытии, чтобы проигрывалась общая анимация. Компонент сам блокирует взаимодействие с закрытой панелью и учитывает настройку уменьшенного движения через общие стили.

Задавайте расположение и оформление панели в стилях раздела. Для панели, открывающейся вверх, задавайте `--hosting-menu-offset: 8px`.

# Анимация блоков в потоке страницы

Для условных блоков, которые сдвигают соседний контент, используйте `AnimatedBlock` из `src/hosting-motion.jsx`. Держите обёртку в DOM и передавайте условие через `open`. Она анимирует раскрытие, закрытие и изменение высоты содержимого. Отступы, которые должны исчезать вместе с блоком, задавайте внутри обёртки.

Для появления статичных карточек и секций при входе на экран используйте общий класс `hosting-reveal`. При проверке интерактивного блока пройдите появление, исчезновение и изменение содержимого. Проверьте, что соседние секции двигаются плавно, а при `prefers-reduced-motion: reduce` состояние меняется сразу.
